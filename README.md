# Zadar Drive - Rent-a-Car Web Stranica

Ovaj projekt je izrađen kao dio kolegija "Uvod u Web tehnologije" na Sveučilištu u Zadru.

## Opis projekta

Zadar Drive je web stranica za rent-a-car uslugu u Zadru. Stranica sadrži informacije o vozilima, kontakt podatke i informacije o agenciji.

## Stranice

- **Početna** (`index.html`) - Glavna stranica sa logom i izdvojenim vozilima
- **Vozila** (`vozila.html`) - Pregled svih dostupnih vozila po kategorijama
- **O nama** (`o_nama.html`) - Informacije o agenciji i poslovnice
- **Kontakt** (`kontakt.html`) - Kontakt forma i podaci za kontakt

## Tehnologije

- HTML5
- CSS3 (responsive dizajn)
- Semantička struktura
- Pristupačnost (ARIA, alt tekstovi)
